# **💰 Expense Tracker**



A simple and responsive Expense Tracker web application built to help users manage their daily expenses efficiently. 
Users can add, track, and manage expenses with an easy-to-use interface.<br><br><br>



## **🚀 Features:**

➕ Add new expenses

📋 View all expense records

🗑️ Delete expenses

📊 Track total spending

💻 Responsive user interface

⚡ Fast and lightweight application<br><br><br>





## **🛠️ Tech Stack:**

Frontend

HTML

CSS

JavaScript

Backend

Node.js

Apache Server

Database

MySQL<br><br><br>

## **⚙️ Installation & Setup:**

#### 1️⃣ Clone the Repository

git clone https://github.com/sasmitha07-cell/Expense-Tracker-.git

#### 2️⃣ Navigate to the Project Folder

cd Expense-Tracker-

#### 3️⃣ Install Dependencies

npm install

#### 4️⃣ Configure MySQL Database

Create a MySQL database

Import the required SQL file (if available)

Update database credentials in your project configuration

Example:

host: "localhost",

user: "root",

password: "your_password",

database: "expense_tracker"


#### 5️⃣ Start the Server

npm start


or


node server.js

🌐 Usage

Open the application in your browser

Add your expenses

View and manage expense history

Track your spending easily
